IDEIA
IDEIA: Automação que recebe vários extratos bancários em PDF, consolida, coloca num padrão financeiro e clusteriza em tipos de custo de acordo com o texto.
Plano de contas bem enxutos para simplificação de leitura e acessibilidade ao usuário final
FLUXOGRAMA e DÚVIDAS
Fluxograma Funcional Inicial (esqueleto simplificado)
Entradas:
Extratos bancários PDF (vários bancos) enviados por usuário (financeiro do cliente).
Etapas:
Upload dos arquivos PDF em repositório (Google Drive / plataforma).
Processamento automático (IDP + OCR) dos PDFs → extração dos lançamentos bancários.
Clusterização/categorização automática (NLP) dos lançamentos conforme plano de contas.
Exibição do resultado para validação por responsável financeiro (“Só confirmar/ajustar categorias?”).
Exportação dos dados estruturados para planilha/dashboard interno.
Envio automático de relatórios consolidado (WhatsApp/email/app).
Saídas:
Planilha estruturada por conta/empresa/semana.
Relatório PMG e alertas para o gestor.

MÓDULO 2 — Categorização via IA com Plano de Contas ACC
1. Critério de aceite:
A IA categoriza cada transação seguindo rigorosamente o "plano de contas – exemplo varejo" fornecido pela ACC
A categorização respeita o padrão de tabela acordado pela ACC
O resultado da categorização é preciso o suficiente para ser validado pela equipe ACC antes de apresentar ao cliente final
O modelo funciona para os segmentos e bancos testados durante o desenvolvimento

Criação de planos de contas personalizados por empresa cliente da ACC

Resumo da automação:
Cliente abre o dashboard e envia um extrato bancário, o extrato é enviado do lovable para a automação v4 no n8n via webhook, onde ele é analisado e enviado de volta para o lovable.
A automação v5 é a responsável por organizar e extrair a tabela do dashboard para uma planilha no excel organizada, ela é ativada (via webhook) ao clicar no botão “exportar para planilha” na aba “resumo” do dashboard.
A automação v5 funciona 100%
Problema: automação V4 não está fazendo a análise correta de extratos, muitas vezes esquece itens ou demora muito tempo para acabar a análise.
Lógica da automação (v4): Ela atua como um sistema de OCR e processamento de dados usando inteligência artificial. Recebe extratos bancários em formato PDF, divide o texto em partes (chunks) para respeitar os limites de leitura da IA, envia esses pedaços para o modelo gpt-4o-mini analisar com base num plano de contas predefinido e, em seguida, formata os resultados estruturados, calculando os saldos linha a linha para serem gravados num banco de dados ou folha de cálculo.
A automação tem que ser responsiva para qualquer tipo de extrato, então não existe uma formatação única e a IA precisa se adequar a todas as situações (que são imprevisíveis, cada banco tem um extrato completamente diferente) e seguir as regras e variáveis impostas pelo cliente (estão no prompt (user message) do “Basic LLM Chain6”)
O maior teste de funcionalidade é testar a automação com o extrato da Bradesco (com 29 páginas: https://drive.google.com/file/d/1YbgklNMpB3YzQtysIQhQMnCwjQWfJjZw/view?usp=drive_link) e verificar se todos os itens foram listados. Se com esse extrato funcionar acho que qualquer um funciona (apesar de que o cliente disse que pode chegar alguém querendo analisar 80+ páginas), então é imprescindível que a análise esteja otimizada.

Estou desenvolvendo uma automação no n8n cujo objetivo é extrair dados de extratos bancários. Estou usando a interface do n8n. A função da automação é replicar as informações do extrato em uma tabela no meu dashboard, as informações que devem ser passadas são as seguintes:
Dados únicos (aparecem somente uma vez):
Nome do banco
Saldo inicial
Saldo Final
Colunas que devem ser inteiramente retiradas da tabela:
Data
Descrição (se houver)
Tipo (crédito (entrada/valores positivos) ou débito (saída/valores negativos)
Valor
Saldo
O saldo pode aparecer ou não no extrato, a automação não precisa extrair o saldo pois consegue calcular ele com base nos outros itens extraídos.
A tabela gerada pela automação deve ser idêntica aos dados do extrato enviado.
A automação irá receber diferentes tipos de extratos de diferentes tipos de bancos, logo não é possível padronizar essa extração de dados e o uso da IA se torna necessário para conseguir analisar qualquer extrato.
O modelo que irei usar será o gpt-4o-mini (se tiver outro modelo com um melhor custo benefício e que seja mais apropriada para meu projeto, me diga)
Anexado a este prompt tem alguns documentos pdf, esses são alguns exemplos que irão passar pela automação.
A automação precisa ser precisa e não pode deixar nenhum item passar (esquecer algum item)
